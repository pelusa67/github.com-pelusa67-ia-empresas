# Umbral · Cómo la IA está transformando a las empresas

Ruta de aprendizaje interactiva sobre la adopción de inteligencia artificial en las empresas: uso, inversión, brecha de valor, casos, empleo, habilidades, México y América Latina, pymes, riesgos, escenario 2030, recomendaciones, laboratorio de prompts y evaluación final.

**Autor:** Angel Israel Orozco Cortés · Licenciatura en Informática Administrativa
**Producto:** Material para evaluación de unidad: Ingeniería de Prompt (octubre de 2026)

## Estructura

```
index.html              Contenido y estructura de los 13 módulos
assets/css/styles.css   Diseño, tema claro/oscuro y adaptación a dispositivos
assets/js/app.js        Interacciones (sin librerías externas)
assets/img/favicon.svg  Ícono del sitio
.nojekyll               Indica a GitHub Pages que publique los archivos tal cual
```

## Publicar en GitHub Pages

1. Crea un repositorio público en GitHub (por ejemplo, `umbral-ia`).
2. Sube **el contenido** de esta carpeta a la raíz del repositorio (`index.html` debe quedar en la raíz). Desde la web: *Add file → Upload files* y arrastra todos los archivos y la carpeta `assets`.
3. Ve a *Settings → Pages*.
4. En *Build and deployment*, elige *Source: Deploy from a branch*, rama `main` y carpeta `/ (root)`. Guarda.
5. En uno o dos minutos el sitio estará en `https://TU-USUARIO.github.io/umbral-ia/`.

> El archivo `.nojekyll` empieza con punto y algunos sistemas lo ocultan. Si no aparece al subir, créalo en GitHub con *Add file → Create new file*, nombre `.nojekyll`, sin contenido.

## Probar en tu computadora

Abre `index.html` con doble clic, o para un entorno idéntico a GitHub Pages ejecuta en la carpeta:

```
python -m http.server 8000
```

y visita `http://localhost:8000`.

## Funciones

- Diseño a todo lo ancho, adaptable a celular, tableta y escritorio.
- Ruta con 13 módulos, progreso guardado en el navegador y navegación por chips.
- Gráficas animadas, comparadores, escalera de valor, explorador de puestos y línea de tiempo.
- Glosario con definiciones emergentes y buscador.
- Autodiagnóstico de preparación para la IA.
- Constructor de prompts con medidor de completitud y bitácora evaluada de 15 prompts.
- Evaluación final de 7 preguntas con retroalimentación.
- Tema claro y oscuro, navegación por teclado, compatibilidad con lectores de pantalla y respeto a la preferencia de movimiento reducido.
